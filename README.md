## Dokumentacja API

### Format specyfikacji

#### Pisanie dokumentacji

- przeczytać [dokumentacje openAPI](https://swagger.io/docs/specification/v3_0/about/) a przynajmniej czytać ją na bieżąco z pisaniem
- używać wersji openapi: 3.0.3
- pisać dokumentacje w .yaml

#### Pisanie kodu na bazie dokumentacji

- przynajmniej troche na bieżąco poczytać dokumentacje
- nie wrzucać do AI
- przeczytać o tym [w jaki sposób konwertować plik w szkielet kodu](https://openapi-generator.tech/docs/usage/)
- używać do tego openapi-generator
